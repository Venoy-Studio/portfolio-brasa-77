# Brasa 77 - Hambúrguer Artesanal

Clone autoral e de alta fidelidade do site [Brasa 77](https://brasa77.lovable.app/) com **remoção total da marca d'água / badge do Lovable**, scripts de rastreamento e dependências proprietárias.

## 🚀 Tecnologias

- **Next.js 14** (App Router & Server Components)
- **React 18** & **TypeScript**
- **Tailwind CSS**
- **Lucide Icons**

## ✨ Funcionalidades & Animações

- **Scroll Burger Separation**: Efeito de física e abertura em camadas do hambúrguer ao rolar a página via `requestAnimationFrame` e interpolação spring.
- **Ember Particles**: Partículas dinâmicas de brasa subindo ao redor do hambúrguer e da grelha.
- **Cardápio Interativo**: Filtro de abas por categoria (*Burgers*, *Acompanhamentos*, *Bebidas*).
- **Cards com 3D Perspective Tilt**: Efeito de inclinação 3D e brilho reflexivo dinâmico seguindo o cursor do mouse.
- **Grill Reveal**: Efeito de revelação suave da carne na grelha com brilho quente contínuo.
- **Integração com WhatsApp**: Botões de CTA e pedido configurados com mensagens dinâmicas personalizadas por produto.
- **Mobile First & Menu Responsivo**: Header flutuante em vidro com menu mobile adaptável.
- **100% Livre de Watermark**: Sem badges, scripts analíticos ou branding de terceiros.

## 📦 Como Rodar

```bash
# Instalar dependências
npm install

# Rodar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
npm start
```
